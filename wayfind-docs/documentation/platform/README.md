# Platform

The Wayfind platform powers the templates, data, and AI capabilities that make agent automation possible.

## Components

### Wayfind Dashboard
Access the dashboard at [wayfind.click](https://wayfind.click/) to:
- Browse and import templates
- Manage API keys
- Track AI credits
- View portfolios and holdings
- Access analytics

### AI Credits
Wayfind uses a credit system to power AI features like risk analysis and multi-agent chat. New users get **1,000 free credits** to get started.

### Architecture
Built on AWS Amplify Gen 2 with serverless functions, DynamoDB, and scheduled data ingestion. Integrates with OpenAI Agents SDK for multi-agent capabilities.
