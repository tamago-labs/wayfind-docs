# Portfolio Management

Track and manage tokenized stock holdings with real wallet data or simulated portfolios.

## Portfolio Types

### Real Portfolios
Connect your wallet and your bot will automatically discover tokenized stock holdings across supported chains. The dashboard tracks balances, values, and allocations.

### Simulated Portfolios
Create practice portfolios to test strategies without using real funds. Add any tokenized stocks and simulate different allocation strategies.

## Features

- **Multi-Wallet Support** - Track holdings across Solana and EVM wallets
- **Token Discovery** - Automatically find tokenized stocks in your wallet
- **Portfolio Stats** - View total value, allocations, and performance
- **Holdings List** - Detailed view of each position with current prices
- **Add Custom Tokens** - Track additional tokens not auto-discovered

## Using with Your Bot

Your bot can help with:
- "Show me my portfolio" - Get an overview of all holdings
- "What's my allocation?" - See breakdown by stock/sector
- "Track this token" - Add tokens to monitor
- "Compare my holdings" - Analyze diversification
