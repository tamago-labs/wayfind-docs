# Payments with MUSD

Use MUSD for payroll, recurring payments, and automated transactions.

## Use Cases

- **Payroll** - Pay contributors, freelancers, or team members
- **Recurring Payments** - Schedule subscriptions or service fees
- **Onchain Payslips** - Generate payment records with transaction hashes
- **Automated Workflows** - Integrate payments into bot workflows

## Features

- **USD-Pegged** - Stable value for predictable payments
- **Fast Settlements** - Quick onchain transfers
- **Programmable** - Automate with bot logic
- **Trackable** - Full onchain payment history

## Multi-Agent Payroll

Similar to the Arc template, use coordinated bots:
1. **HR Bot** - Manages payment schedules and recipient details
2. **Finance Bot** - Reviews and executes payments
3. **Approval Workflow** - Human approval before execution
4. **Payslip Generation** - Automatic record keeping

## Using with Your Bot

- "Pay 500 MUSD to 0x..." - Send payment
- "Schedule monthly payment of 1000 MUSD" - Set up recurring
- "Generate payslip for last payment" - Create payment record
- "Pay all freelancers this week" - Batch payments with approval
- "Check MUSD balance" - View available funds
