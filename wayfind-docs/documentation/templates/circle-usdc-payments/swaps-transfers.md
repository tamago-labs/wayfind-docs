# Swaps & Transfers

Send and receive USDC/EURC, swap tokens, and move funds across chains.

## Transfers

- **Send USDC/EURC** - Transfer to any address on supported chains
- **Receive** - Get funds from anywhere
- **Cross-Chain** - Move between chains seamlessly via unified balance

## Swaps

Swap tokens via Circle Swap Kit:
- **Supported Pairs** - USDC, WETH, cirBTC and more
- **Best Routes** - Optimized for price and fees
- **Approval Workflows** - All swaps require approval

## Using with Your Bot

- "Send 50 USDC to [address]" - Transfer funds
- "Swap USDC for WETH" - Execute token swap
- "Move USDC from Ethereum to Arc" - Cross-chain transfer
- "Convert EURC to USDC" - Currency conversion
