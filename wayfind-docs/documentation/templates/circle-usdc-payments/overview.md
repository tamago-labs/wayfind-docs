# Circle USDC Payments - Overview

The Circle USDC Payments template integrates with Circle App Kits to enable cross-chain USDC payments, unified balance management, and automated financial workflows for your Grok Bot.

## Key Features

- **Unified Balance** - Manage USDC across 12+ chains with Circle's unified balance
- **Cross-Chain Transfers** - Send and receive USDC and EURC seamlessly
- **Token Swaps** - Swap tokens via Circle Swap Kit
- **Earn Yield** - Access yield opportunities through vaults like Morpho
- **Multi-Agent Workflows** - CFO, HR, Research, Marketing bots coordinate together
- **Payroll Automation** - Track freelancers, schedule payments, generate onchain payslips

## Supported Networks

Arc, Ethereum, Solana, Base, Arbitrum, Polygon, Avalanche, Optimism, and more.

## What's Inside

- **Frontend** - Next.js landing page and dashboard
- **MCP Server** - 13 tools for wallet, swaps, unified balance, earn via Circle App Kits
- **Agent Skills** - Claude, Cursor, Grok Bot manifests and intent routing

## Proven on Arc Mainnet

Wayfind bots have executed real transactions on Arc Mainnet:
- EURC → USDC swaps via Circle App Kit
- USDC deposits to Unified Balance
- USDC payments from Unified Balance
