# Templates

Choose a template based on what you want your AI bot to do. Each template comes with specialized skills, tools, and workflows.

## Getting Started with Templates

1. **Browse** - Visit [wayfind.click](https://wayfind.click/) to see all templates
2. **Import** - Click import to add to Grok Bot, or set up via MCP
3. **Configure** - Follow the bot's setup instructions (wallet creation, API keys if needed)
4. **Use** - Start chatting with your bot to use template capabilities

## Template Components

Every Wayfind template includes:
- **Agent Skills** - Role-specific instructions and capabilities
- **MCP Tools** - Blockchain interactions, data queries, transaction execution
- **Workflows** - Pre-built patterns for common tasks
- **Multi-Agent Support** - Can work alongside other bots in a team
