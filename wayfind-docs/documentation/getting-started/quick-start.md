# Quick Start

Get started with Wayfind in just a few minutes.

## For Grok Bot Users (Fastest)

1. **Browse Templates** - Go to [wayfind.click](https://wayfind.click/) and select a template
2. **Import** - Click "Import to Grok Bot" to add the template to your bot
3. **Setup** - Open the template in Grok Bot and let it guide you through wallet creation
4. **Go** - Ask your bot to help with its use case (e.g., "List all stock tokens relating to TSLA")

## For Other AI Agents

1. **Install MCP** - Add the relevant Wayfind MCP server to your agent config
2. **Get API Key** - Get your key from [wayfind.click](https://wayfind.click/) dashboard
3. **Configure** - Add environment variables and restart your agent
4. **Test** - Ask your agent to use Wayfind tools
