# Setting Up Grok Bot

Get started with Wayfind on Grok Bot in just a few minutes.

## Prerequisites

- [Grok Bot](https://x.ai/grok-bot) installed
- Access to [wayfind.click](https://wayfind.click/) to browse templates

## Steps

### 1. Browse and Import Template
1. Go to [wayfind.click](https://wayfind.click/)
2. Select the template you want to use (Solana Tokenized Stocks, Circle USDC Payments, or Mezo Bitcoin Finance)
3. Click "Import to Grok Bot" to add it to your bot

### 2. Configure Your Bot
1. Open the imported template in Grok Bot
2. Set your `WALLET_PASSKEY` environment variable on the bot computer
3. Let the bot guide you through creating your agentic wallet

### 3. Add API Key (If Needed)
Some templates (like Solana Tokenized Stocks) require a Wayfind API key for full functionality:
1. Get your API key from [wayfind.click](https://wayfind.click/) dashboard
2. Provide it to your bot when prompted

### 4. Start Using Your Bot
Once setup is complete, you can start chatting with your bot. Ask it to help with tasks specific to your template - track portfolios, send payments, manage positions, etc.

## Important Notes

- **Wallet Backup:** Grok Bot's bot computer can occasionally reset data. Back up your `BACKUP_AND_REMOVE.txt` file so you can restore your wallet if needed.
- **Approval Workflows:** Your bot will prepare transactions for your review and approval before executing them.
- **Multi-Agent Teams:** You can create multiple bots with different roles (CFO, HR, Research, etc.) and have them work together.
