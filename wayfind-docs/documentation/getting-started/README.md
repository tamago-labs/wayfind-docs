# Getting Started

Get up and running with Wayfind in minutes. Choose your path based on how you want to use it.

## Choose Your Setup

| Use Case | Recommended Path | Time to Setup |
|----------|-------------------|---------------|
| **Grok Bot (Recommended)** | [Quick Start](quick-start.md) | ~1-3 minutes |
| **Meta Muse, OpenAI Dots, Claude Duet** | Import Agent Skills from the template's skills repo (see template setup) | ~3-5 minutes |
| **Cursor, Cherry Studio, etc. (Desktop Apps)** | Configure MCP server for your agent (see [MCP Servers](../for-ai-agents/mcp-servers.md)) | ~10-15 minutes |
| **Quick Preview** | [Quick Start](quick-start.md) | ~2 minutes |

## Prerequisites

- [Grok Bot](https://x.ai/grok-bot) installed (for Grok Bot path)
- Access to [wayfind.click](https://wayfind.click/) to browse templates
- A wallet for the blockchain you'll be using (created automatically by bot)
- For some features, a Wayfind [API key](api-keys.md)

## Quick Overview

1. **Browse** - Go to [wayfind.click](https://wayfind.click/) and pick a template
2. **Import** - Import to Grok Bot or configure MCP for your agent
3. **Configure** - Set up wallet, API key (if needed), and bot role
4. **Start** - Tell your bot what to do and watch it work
