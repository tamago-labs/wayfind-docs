# Repositories

All Wayfind code is open source under the [tamago-labs](https://github.com/tamago-labs) organization.

## Core Repos

| Repository | Description |
|------------|-------------|
| [wayfind](https://github.com/tamago-labs/wayfind) | Main platform - Next.js dashboard, AWS Amplify backend, AI risk engine |
| [wayfind-mcp](https://github.com/tamago-labs/wayfind-mcp) | MCP server for Solana Tokenized Stocks (`@tamago-labs/wayfind-mcp`) |
| [wayfind-skills](https://github.com/tamago-labs/wayfind-skills) | Agent skills for Grok Bot and other agents |

## Template-Specific Repos

| Repository | Description |
|------------|-------------|
| [wayfind-arc](https://github.com/tamago-labs/wayfind-arc) | Circle USDC Payments template - frontend, MCP server, agent skills for Arc |
| [wayfind-mezo](https://github.com/tamago-labs/wayfind-mezo) | Mezo Bitcoin Finance template - MCP server and agent skills |
