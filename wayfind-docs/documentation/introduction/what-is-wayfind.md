# What is Wayfind?

Wayfind is an AI Agent Infrastructure platform that equips [Grok Bot](https://x.ai/) with ready-to-use templates, agent skills, and MCP tools to automate onchain actions across multiple blockchains.

## The Problem

Managing onchain operations - trading tokenized stocks, processing payments, or running DeFi strategies - requires constant monitoring and execution. AI agents are capable, but they need the right tools, data, and workflows to do it effectively.

## The Solution

Wayfind provides purpose-built templates that turn your Grok Bot into a specialized onchain operator. Each template comes with:
- **Pre-configured skills** - Domain expertise baked in
- **MCP tools** - Direct blockchain and protocol interactions
- **Workflows** - Proven patterns for automation with approvals
- **Multi-agent coordination** - Teams of bots working together

## Who It's For

- **Crypto users** wanting to automate portfolio management, payments, or DeFi
- **Teams** needing payroll automation across chains
- **DeFi users** looking to automate Bitcoin finance strategies
- **Agent builders** wanting to extend AI agents with onchain capabilities

## Built For Grok Bot

Wayfind is optimized for [Grok Bot](https://x.ai/grok-bot) - X.AI's always-on AI agents that run on dedicated computers. Templates can be imported with one click, and bots coordinate as teams to handle complex workflows around the clock.
